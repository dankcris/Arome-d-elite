# Arome-d-elite
proyecto de perfumes
avance tienda arome d'elite - evaluacion parcial 1
curso: fullstack 2, seccion 12D
integrantes: tomas gonzalez, matias noriega, matias obreque

hicimos las 3 paginas de la tienda (inicio, productos y contacto)
usando header, nav, main, section, article y footer como vimos en clases.

- inicio: bienvenida, historia de la tienda y el producto destacado
- productos: los perfumes separados en masculinos, femeninos y unisex,
  con un boton para agregarlos a un carrito simple hecho en js
- contacto: formulario que valida con js que el nombre, correo y
  mensaje esten bien escritos antes de enviar, mas un video

el css esta en un archivo aparte (estilo.css) para que las 3 paginas
usen el mismo diseño
